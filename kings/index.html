Reigns run from accession to the end of the reign in each ruler’s main realm, to the nearest month. Birth years marked “c.” are uncertain, so those ages are approximate. Every bar is labelled, so colour is never the only way to tell realms apart. Each flag is the flag, royal banner or emblem used during that reign. Rulers who lived before heraldry are shown with the banner later tradition gave them, marked “Later tradition”.
